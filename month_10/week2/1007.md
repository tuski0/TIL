### React, Next.js의 차이

- React
  - 라이브러리
  - 빌드 => js를 사용하여 동적으로 페이지 출력
  - Client Side Rendering
    - 인터넷 연결 없이 화면 출력
    - 화면 전환 속도 빠름
    - 약간의 초기 로딩 지연
- Next.js
  - 프레임워크 (React 기반)
  - Server Side Rendering
    - prerender : 서버에서 번역해서 내용있는 HTML을 전송
    - hydration : HTML에 동적 JS 특성 반영
  
### package.json : 프로젝트 명세
- dependencies : 실제 배포시 포함 => npm i 의존성명
- devdependencies : 개발시에만 필요한 의존성
- scripts : npm run으로 실행하는 명령어 설정

### 모듈 가져오기 내보내기
- export : 모듈 내보내기 => 다른 파일에서 공유 가능
- import : 모듈 가져오기 
  - import 모듈명 from 모듈 경로; 
  


### Java Script XML , Type Script XML
- < tag > ... < /tag > 형식
- 단일 태그 JSX -> 끝맺음 기호 필수 < tag /> 
- (...) 안에 JSX 객체 정의
- 변화 감지 효율성을 높이기 위해서 컴포넌트는 단일 노트로 구성 -> 출력하지 않는 단일 컴포넌트 Fragment 
  - `<>, </> === <Fragment> </Fragment>`
- JSX 문법상에서 JS 사용하는 경우 {..} 안에 작성해야 동작 
- 조건식 : 삼항조건, && 연산자
- 주석 {/* */}, 한줄은 // 줄 개행 필수
- React.JSX.Element : JSX 요소만 반환
- React.ReactNode : JSX 요소 + 다른 형태의 값 ( 문자열, 숫자, null, 함수, 객체)
