# 클래스

#### 객체 ( Object )

- 속성(변수), 행위(함수)로 구성

### 클래스

- 객체를 만들기 위해 속성과 행동을 정의해둔 설계도

```python
class Bus:
    # 속성 정의
    def __init__ (self):
        self.count = 0 # 승객 수, 변수 초기화

    def ride(self): # 탑승
        self.count += 1
        print('탑승')

    def off(self):
        if self.count >= 1:
            self.count -= 1
        print('하차')

    def show_count(self):
        print('승객 수 : ', self.count)

    def print_self(self):
        print(id(self))
```

```python
bus1 = Bus() # 객체, 클래스 -> 객체 (인스턴스)

# . 연산자를 통해 객체의 인스턴스 변수, 메서드에 접근
print('탑승객 수 : ', bus1.count) # 탑승객 수 : 0
bus1.ride() # 탑승
bus1.off() # 하차
```

```python
bus1 = Bus()
print('bus1 주소 : ', id(bus1)) # bus1 주소 :  4433648912
bus1.print_self() # 4433648912
```

### 초기화 함수 \_\_init\_\_ (생성자)

- 객체가 생성시에 가장 먼저 호출되는 메서드
- 객체가 생성된 직후에 해야 할 작업들 (초기화 작업)
- 주 작업 : 인스턴스 변수에 최초로 값을 할당
- self 이후 매개변수는 객체를 생성할때 외부에서 초기화 값을 지정할 수 있음

### Self 키워드

- 클래스 내부에서 메서드의 첫번째 매개변수로 정의
- 객체가 생성이 되면 객체의 자원에 접근하기 위한 참조 변수
- 클래스 내부에서만 사용 가능

### 속성(Attribute) & 인스턴스 메서트(Method)

- 속성 : 객체마다 정의된 (인스턴스) 변수
- 메서드 : 객체가 가지고 있는 함수

```python
class Bus:
    # 속성 정의
    def __init__ (self):
        self.count = 0 # 승객 수, 변수 초기화
        self.passengers = []

    def ride(self, passenger): # 탑승
        self.count += 1
        self.passengers.append(passenger)
        print('탑승')

    def off(self, passenger):
        if self.count >= 1:
            self.passengers.remove(passenger)
            self.count -= 1
        print('하차')

    def show_count (self):
        print('승객 수 : ', self.count)

    def print_self(self):
        print(id(self))

class Passenger :
    pass
```

```python
bus = Bus()
p1 = Passenger()
p2 = Passenger()

bus.ride(p1) # 탑승, count + 1
bus.ride(p2) # 탑승, count + 1

bus.show_count() # 2
```

### \_\_str\_\_ & \_\_repr\_\_

- \_\_str\_\_
  - print롤 객체의 참조변수를 출력하면 자동으로 호출하는 메서드
  - 보통 객체 내의 인스턴스 변수의 내용을 출력
  - 사용자 대상 편의성 제공 용도로 사용

- \_\_repr\_\_
  - print 하면 자동으로 호출, str이 우선순위 높음
  - 개발자 대상 디버깅 용도로 사용: 클래스명(매개변수=값, ...) -> eval() 문자열을 실행 했을때 객체가 만들어지는 형태로 정의
  - repr(객체 참조 변수)

```python
class Passenger :
    # self.name, self.age -> 객체가 생성될때 만들어지는 인스턴스 변수
    # name, age -> 객체를 생성하기 위해 매개변수로 정의된 지역변수
    def __init__ (self, name, age):
        self.name = name
        self.age = age

    def __str__ (self):
        return f'이름 : {self.name}, 나이 : {self.age}'

    def __repr__(self):
        return f'Passenger(name={self.name}, age={self.age})'

p1 = Passenger('김철수', 20)
print(p1)  # __str__ 호출 | 이름 : 김철수, 나이 : 20
print(repr(p1)) # __repr__ 호출 | Passenger(name=김철수, age=20)
```

# 상속 & 캡슐화

### 1. 상속

- 클래스 기반 상속 ( 상속에 대한 정의 -> 객체 생성 ( 상속 관계 성립 ) )

```python
class 자식 클래스(부모 클래스):
    ...
```

- 부모 클래스 : 일반적인 정의, 상위 개념
- 자식 클래스 : 구체적인 정의, 하위 개념

```python
class Animal:
    def __init__(self, kind):
        self.kind = kind # 종

    def move(self):
        print('동물이 움직임')

class Dog(Animal):
    def __init__(self):
        super().__init__('강아지') # 부모쪽 인스턴스 변수인 kind에 초기화


class Cat(Animal):
    def __init__(self):
        super().__init__('고양이')

```

```python
dog = Dog())
print(dog.kind) # 강아지
dog.move() # 동물이 움직임

cat = Cat()
print(cat.kind) # 고양이
cat.move() # 동물이 움직임

```

### 2. 메서드 오버라이딩

- 메서드 재정의
- 부모 쪽 클래스와 동일한 이름으로 정의하여 기능을 수정, 재정의
- 자식 쪽 클래스에 정의된 동일한 이름의 함수가 호출 우선순위를 가짐
- 자식에서 부모의 동일한 이름의 메서드를 호출해야 하는 경우에는 self 접근 불가능
  - super().부모쪽 메서드 접근(..)

```python
class Animal:
    def __init__(self, kind):
        self.kind = kind # 종

    def move(self):
        print('동물이 움직임')

class Dog(Animal):
    def __init__(self, kind):
        super().__init__(kind) # 부모쪽 인스턴스 변수인 kind에 초기화

    def move(self):
        print(f'{self.kind} 걸음으로 움직임')

class Cat(Animal):
    def __init__(self, kind):
        super().__init__(kind)

    def move(self):
        print(f'{self.kind} 걸음으로 움직임')
```

```python
dog = Dog('강아지')
cat = Cat('고양이')

dog.move() # 강아지 걸음으로 움직임
cat.move() # 고양이 걸음으로 움직임
```

### 3. 객체의 출처(클래스 자료형) 확인하는 함수

- isinstance(참조 변수, 클래스/자료형)

```python
class Human:
    def move(self):
        print('두 발로 직립보행')

print('human 은 Animal 클래스로부터 생성 되었는지 : ', isinstance(human, Animal))

print('human은 Human 클래스로부터 생성 되었는지 : ', isinstance(human, Human))
# True

print('dog은 Animal 클래스로부터 생성 되었는지 : ', isinstance(dog, Animal))
# True
```


### 4. 다중 상속

- 여러 부모 클래스를 상속 관계로 정의 가능
- 다중 상속시 같은 메서드가 있을때 호출 우선 순위 (MRO)
  - 자식 클래스의 메서드 -> 상속 관계에서 왼쪽에 있는 클래스 ->

```python
class ParentA:
    def a(self):
        print('ParentA - a()')

    def b(self):
        print('ParentA - b()')

class ParentB:
    def a(self):
        print('ParentB - a()')

    def c(self):
        print('ParentB - c()')

class Child(ParentA, ParentB):
    pass
```

```python
child = Child()

child.a() # ParentA - a()
child.b() # ParentA - b()
child.c() # ParentB - c()
```

### 6. 정보 은닉 & 캡슐화 ( Encapsulation )

```python
class Schedule:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    def __str__(self):
        return f'year={self.year}, month={self.month}, day={self.day}'

s1 = Schedule(2026, 8, 18)

print(s1) # year=2026, month=8, day=18

s1.year = 2026
s1.month = 2
s1.day = 31

print(s1) # year=2026, month=2, day=31
```

### 7. 프라이빗 변수 & 이름 변형 규칙

- \_\_변수명 : 클래스 내부에서만 접근 가능한 인스턴스 변수가 됨

```python
class Schedule:
    def __init__(self, year, month, day):
        self.__year = year
        self.__month = month
        self.__day = day

    def __str__(self):
        return f'year={self.__year}, month={self.__month}, day={self.__day}'

s1 = Schedule(2026, 8, 18)

print(s1) # year=2026, month=8, day=18

# 인스턴스 변수에 직접 대입이 가능하므로 값에 대한 통제는 불가능
# 통제 불가능 -> 직접 접근을 막아야 함
s1.__year = 2026
s1.__month = 2
s1.__day = 28

print(s1) # year=2026, month=8, day=18
```

### 8. Getter, Setter 메서드

```python
class Schedule:
    def __init__(self, year, month, day):
        self.__year = year
        self.__month = month
        self.__day = day

    def get_year(self):
        return self.year

    def get_month(self):
        return self.month

    def get_day(self):
        return self.day

    def set_year(self, year):
        self.__year = year

    def set_month(self, month):
        self.__month = month

    def set_day(self, day):
        self.__day = day

    def __str__(self):
        return f'year={self.__year}, month={self.__month}, day={self.__day}'
```

```python
s1 = Schedule(2026, 8, 18)
s1.set_month(2)
s1.set_day(31)

print(s1) # year=2026, month=2, day=31
```
