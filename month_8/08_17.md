# 클래스

### 클래스 변수 (정적 변수) & 인스턴스 변수

- 클래스 생성 이후에도 동적으로 클래스 변수를 생성가능하다.

```python
class User:
    pass

user = User()
user.name = '김철수'
user.age = 20

print(user.name, user.age)
```

```python
class User :
    count = 0

user1 = User()
user2 = User()

print(user1.count()) # 인스턴스 변수
print(user2.count()) # 인스턴스 변수

User.count = 100
print(User.count) # 클래스 변수
```

### @classmethod & @staticmethod

- 객체를 생성하지 않아도 접근할 수 있는 메서드 정의 시에 사용

```python
class Calculator:

    count = 0

    # clz -> Calculator 클래스 객체 참조 변수
    # clz -> 클래스 변수, 다른 클래스 메서드를 접근하기 위한 목적
    @classmethod
    def add(clz, num1, num2):
        clz.count += 1
        print('호출 횟수 : ', clz.count)
        return num1 + num2

    @staticmethod
    def minus(num1, num2):
        return num1 - num2

Calculator.add(10, 20)
Calculator.minus(20, 10)
```

### 3. try - except - else - finally

- 예외처리 구문
- 모든 예외 클래스는 Exception의 자식 클래스
- 예외를 특정하지 못하는 경우 Exceptiond으로 처리 가능

```python
try :
    # 예외가 발생할 가능성이 있는 코드
except:
    # 예외 발생시 유입되는 구간, 예외의 대안 처리
    # 대안 로직, 로깅 추가
else :
    # 예외가 발생하지 않아야 유입되는 구간
finally:
    # 예외 발생, 정상 출력에서 항상 유입되는 구간, 공통적인 처리
    # 자원 정리(메모리 해제 등)

```

```python
try :
    num = int(input())
    result = 10 / num
    print(result)
except:
    print('0 넣으면 안댐')
else:
    print('정상 처리')
finally:
    print('로깅 처리')

# num = 0 -> 0 넣으면 안댐
# num = 1 -> 10.0
```


### 사용자 정의 예외

- Exception은 모든 예외의 부모클래스
- Exception을 상속 받으면 또는 Exception을 상속 받은 자식 클래스를 상속 받으면 그 클래스도 예외

```python
def login(user_id, user_pass):

    if user_id != 'user01':
        raise UserIdMismatchError('아이디가 일치하지 않음') # 예외 발생, 코드 실행 흐름 중단

    if user_pass != '1234':
        raise UserPassMismatchError('비밀번호가 일치하지 않음')

    print('로그인 성공')
```

# 내장 함수

### all() & any()

- all() : 모든 요소가 True 일때 - True / 빈 리스트([]) -> True
- any() : 모든 요소 중 하나만 True 여도 - True

```python
all([True, 1, " "]) # True
all([False, "", False]) # False

any([True, "", False]) # True
any([]) # False
```

### len, sum, round

- len : 문자열 -> 문자열의 길이 / 리스트, 튜플 -> 요소의 갯수
- sum : 요소의 합
- round : 실수를 반올림하여 정수로 변환 : Math.ceil(..) 올림 / Math.floor(..) 내림

```python
num = 10.56
print(round(num, 1)) # 소숫점 1번째 자리까지 올림
print(round(num)) # 정수 첫째 자리로 올림

import math # 수학 함수
print(math.ceil(num)) # 올림
print(math.floor(num)) # 내림
```

### mean( ) & median( )

- statistics 모듈에 포함된 표준 라이브러리
- mean( ) : 평균
- median( ) : 중간값

```python
import statistics

nums = [10, 15, 20, 8, 7, 100000]
print('평균 : ', statistics.mean(nums), '중앙값 : ' , statistics.median(nums))
# 평균 :  16676.666666666668 중앙값 :  12.5
```
